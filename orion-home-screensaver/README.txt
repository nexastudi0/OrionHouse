MODO CASA
- Comando por voz com palavra de ativacao "Orion"
- Adicionar itens manualmente
- Remover itens
- Limpar comprados
- Limpar toda a lista
- Ler lista em voz alta
- Marcar itens como comprados

MODO RUA
- Sem microfone/comando de voz
- Exibe a lista de compras
- Permite marcar itens como comprados
- Interface simplificada para celular
- Nao permite adicionar, excluir ou limpar itens

IMPORTANTE SOBRE SINCRONIZACAO
Esta versao ainda salva os dados no localStorage do navegador. Isso significa que a lista e os logins funcionam localmente no aparelho/navegador usado.
Para a lista criada no tablet/computador de casa aparecer automaticamente no celular na rua, conecte o projeto a um banco online como Supabase. A interface desta versao ja esta separada em perfis Casa e Rua para facilitar essa proxima etapa.

SEGURANCA
Os acessos desta versao sao de demonstracao e ficam no codigo do projeto. Para uso real pela internet, use autenticacao no servidor/Supabase e troque as credenciais.
